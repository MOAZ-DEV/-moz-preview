# Moz Preview
A library that helps display page responsive variants with pixel-perfect development support.

Features:
- Easy to use out of the box:
  - Install with `bun install @crow/preview`
  - Set up the provider
  - Add props or customize as needed
- Display images or Figma pages for comparison
- Toggle on/off

Future features:
- Click to open components in an IDE
- Export preview files
- Share live results online via peer-to-peer connection
- Store comments
- Extremely lightweight

# libraries

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.4.2. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
